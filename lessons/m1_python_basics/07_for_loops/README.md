# Lesson 7 · for loops

A `for` loop repeats code for each item.

```python
for n in range(3):
    print(n)      # 0, 1, 2
```

`range(start, stop, step)` counts from start up to **but not including** stop:

```python
range(1, 4)       # 1, 2, 3
range(10, 0, -1)  # 10, 9, ... 1
```

Code inside the loop is indented 4 spaces. Code after the loop is not.
