# Lección 6 · if / elif / else

Tu programa puede decidir qué hacer.

```python
temp = 30
if temp > 28:
    print("Calor")
elif temp >= 18:
    print("Agradable")
else:
    print("Frío")
```

- La línea termina con dos puntos `:`.
- El código de adentro va corrido a la derecha con **4 espacios**.
- Compara con `==` (igual), `!=` (diferente), `<`, `>`, `<=`, `>=`.
- `=` guarda un valor. `==` hace una pregunta.
