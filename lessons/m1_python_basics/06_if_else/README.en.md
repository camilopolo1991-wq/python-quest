# Lesson 6 · if / elif / else

Your program can choose what to do.

```python
temp = 30
if temp > 28:
    print("Hot")
elif temp >= 18:
    print("Nice")
else:
    print("Cold")
```

- The line ends with a colon `:`.
- The code inside is pushed right with **4 spaces**.
- Compare with `==` (equal), `!=` (not equal), `<`, `>`, `<=`, `>=`.
- `=` saves a value. `==` asks a question.
