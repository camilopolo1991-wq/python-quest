# Lección 1 · print()

`print()` muestra texto en la pantalla. El texto va entre comillas.

```python
print("¡Hola, mundo!")
print("Estoy aprendiendo Python")
```

Cada `print()` empieza una línea nueva. Los números se pueden imprimir sin comillas:

```python
print(2026)
```

**Error común:** olvidar las comillas. `print(Hola)` da un `NameError`, porque Python cree que `Hola` es el nombre de una variable.
