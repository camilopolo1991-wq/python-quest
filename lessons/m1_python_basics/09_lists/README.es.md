# Lección 9 · Listas

Una lista guarda muchos valores en orden.

```python
frutas = ["mango", "lulo", "banano"]
print(frutas[0])          # mango (las listas cuentan desde 0)
frutas.append("guayaba")  # agrega al final
print(len(frutas))        # 4
for f in frutas:
    print(f)
```

Útiles: `max(lista)`, `min(lista)`, `sum(lista)`, `len(lista)`.
