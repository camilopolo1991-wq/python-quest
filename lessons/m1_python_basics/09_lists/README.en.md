# Lesson 9 · Lists

A list keeps many values in order.

```python
fruits = ["mango", "lulo", "banana"]
print(fruits[0])        # mango (lists count from 0)
fruits.append("guava")  # add to the end
print(len(fruits))      # 4
for f in fruits:
    print(f)
```

Useful: `max(list)`, `min(list)`, `sum(list)`, `len(list)`.
