# Lesson 3 · Math

| Symbol | Meaning | Example | Result |
|---|---|---|---|
| `+` `-` `*` `/` | add, subtract, multiply, divide | `7 / 2` | `3.5` |
| `//` | whole division | `7 // 2` | `3` |
| `%` | remainder | `7 % 2` | `1` |
| `**` | power | `2 ** 3` | `8` |

```python
fare = 2950
trips = 2
print(fare * trips)   # 5900
```

Python follows normal math order. Use `( )` when in doubt.
