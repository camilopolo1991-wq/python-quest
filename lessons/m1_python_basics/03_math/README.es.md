# Lección 3 · Matemáticas

| Símbolo | Significa | Ejemplo | Resultado |
|---|---|---|---|
| `+` `-` `*` `/` | sumar, restar, multiplicar, dividir | `7 / 2` | `3.5` |
| `//` | división entera | `7 // 2` | `3` |
| `%` | residuo | `7 % 2` | `1` |
| `**` | potencia | `2 ** 3` | `8` |

```python
pasaje = 2950
viajes = 2
print(pasaje * viajes)   # 5900
```

Python sigue el orden normal de las matemáticas. Usa `( )` si tienes dudas.
