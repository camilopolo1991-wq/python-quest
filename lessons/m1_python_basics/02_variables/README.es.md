# Lección 2 · Variables

Una variable es una caja con etiqueta que guarda un valor.

```python
jugador = "Pip"
vidas = 3
print(jugador)
print(vidas)
```

Puedes cambiar lo que hay en la caja:

```python
vidas = vidas - 1   # ahora vidas vale 2
```

**Reglas para los nombres:** letras, números y `_`, sin espacios y sin empezar por número. `mi_puntaje` está bien, `mi puntaje` no.
