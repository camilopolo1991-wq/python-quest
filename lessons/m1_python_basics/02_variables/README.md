# Lesson 2 · Variables

A variable is a labeled box that keeps a value.

```python
player = "Pip"
lives = 3
print(player)
print(lives)
```

You can change what's in the box:

```python
lives = lives - 1   # now lives is 2
```

**Rules for names:** letters, numbers and `_`, no spaces, can't start with a number. `my_score` is good, `my score` is not.
