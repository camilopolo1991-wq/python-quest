# Build · Tip Splitter 🧾

**Your first real program.** No starter code this time: you plan it.

Your friends and you finish dinner. Write `build.py` that:

1. Asks, in this order: `Bill: `, `People: `, `Tip %: `
2. Adds the tip to the bill.
3. Splits it between the people.
4. Prints `Each pays: 82500.00` (always 2 decimals).
5. If each person pays more than 50000, also prints `Expensive night!`

Example:

```
Bill: 300000
People: 4
Tip %: 10
Each pays: 82500.00
Expensive night!
```

Try it yourself many times with different numbers before you check. Real programmers test their own code first.

**Stretch goals (no extra tests):** print the tip amount too, or refuse 0 people with a friendly message.
