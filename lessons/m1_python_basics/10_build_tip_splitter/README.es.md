# Proyecto · Divide la cuenta 🧾

**Tu primer programa de verdad.** Esta vez no hay código inicial: tú lo planeas.

Terminas de comer con tus amigos. Escribe `build.py` que:

1. Pregunte, en este orden: `Cuenta: `, `Personas: `, `Propina %: `
2. Sume la propina a la cuenta.
3. Divida el total entre las personas.
4. Imprima `Cada uno paga: 82500.00` (siempre 2 decimales).
5. Si cada persona paga más de 50000, imprima también `¡Noche cara!`

Ejemplo:

```
Cuenta: 300000
Personas: 4
Propina %: 10
Cada uno paga: 82500.00
¡Noche cara!
```

Pruébalo tú mismo muchas veces con números distintos antes de revisar. Los programadores de verdad prueban su propio código primero.

**Retos extra (sin pruebas):** imprime también el valor de la propina, o rechaza 0 personas con un mensaje amable.
